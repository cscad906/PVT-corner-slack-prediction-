## 무엇이 달라졌나 (참고)

원본과 기능은 같고, 2.7 문법으로만 바꾼 것입니다.

- f-string → `"{}".format(...)`
- `open(..., errors=)` → 읽기는 `io.open`, 쓰기는 `open`
- `functools.lru_cache` → 같은 동작을 직접 구현
- `from __future__ import division, print_function`
