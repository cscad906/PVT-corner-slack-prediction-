# 결과 코드표

각 스크립트는 끝에 **무엇이 문제인지 + 무엇을 하면 되는지 + 코드**를 함께 찍습니다.

```
==================================================================
  문제 발생
    무엇이   : SPEF 에서 저항(Res)을 하나도 못 구했습니다
    하실 일  : SPEF 가 이 리포트와 같은 디자인/코너인지 확인해 주세요.

    에러 코드: E-RES0
    (해결이 안 되면 이 코드를 알려주세요)
==================================================================
```

**`하실 일` 을 먼저 해 보시고**, 안 되면 코드를 알려주세요.

- `정상 종료 [ OK-… ]` → 다음 단계로.
- `확인 필요 [ W-… ]`  → 파일은 나왔지만 데이터가 불완전.
- `문제 발생 [ E-… ]`  → 그 단계 결과가 안 만들어짐.

아래는 전체 목록입니다. 화면에 나오는 것과 같은 내용이라, 종이로 뽑아 두면
화면을 못 볼 때도 참고할 수 있습니다.

---

## 정상 코드

| 코드 | 어느 단계 | 뜻 |
|---|---|---|
| `OK-UNION` | 1_union | 합집합 완료. 2회차로 |
| `OK-CPIN` | 2a_cpin | Cpin 정상 |
| `OK-DISTRES` | 2b_distres | Dist/Res 정상 |
| `OK-MERGE` | 2c_merge | `<코너>_fixed_annotated.txt` 완성 |
| `OK-XCTX` | 5a_contexts | PT 에 물어볼 넷 목록 완성 |
| `OK-XTALK` | `xtalk_all.tcl` (PT 안) | crosstalk 계산 완료. 셸로 돌아가 5b 로 |
| `OK-XPAIR` | 5b_pairs | victim-aggressor 쌍 뽑기 완료 |
| `OK-XRPT` | 5c_report | **14열 리포트 완성 (모델 입력)** |

`4_all_corners.py` 는 코너별 결과 표에 위 코드를 그대로 찍습니다.
표에만 나오는 두 가지:

| 표시 | 뜻 |
|---|---|
| `SKIP` | `--skip-done` 이라 이미 있는 결과를 건너뜀 |
| `NOSPEF` | SPEF 가 없어 그 단계를 건너뜀. `--spef` 로 주거나 폴더에 `design.spef` |
| `-` | 앞 단계가 실패해서 아예 안 돈 것 |

이 다섯이 순서대로 나오면 그 코너는 끝난 것입니다.

## 주의 코드 — 결과는 있지만 봐야 함

| 코드 | 뜻 | 할 일 |
|---|---|---|
| `W-DROP` | 합집합에서 버린 경로가 10% 넘음 | `report_timing` 에 `-nets -input_pins -nosplit -path_type full_clock_expanded` 를 다 넣었는지 확인 |
| `W-CPIN` | Cpin 이 10% 넘게 빔 | 받은 Cpin 표(`cpin_map.txt`)에 그 핀들이 있는지. 2a 화면의 `1열 판별` 확인 |
| `W-CPINCOL` | `2a_cpin.py` | `--cpin-map` 에서 고른 값이 넷 전체 cap 과 같음 | pin cap 대신 wire cap 열을 집었을 수 있다. `--cpin-col` 로 다른 열 선택 |
| `W-RES` | Res 가 10% 넘게 빔 | `2c_merge.py` 화면의 `[원인 A/B/C]` 줄 확인 (자동) |
| `W-NA` | 결과에 N/A 있음 | 위와 같음 |
| `W-NETKEY` | 받은 표가 넷 이름만이라 리시버가 여럿인 넷은 그 줄들이 같은 값을 받음 (`2b_distres_table.py`) | 상대에게 driver/receiver 핀 열 2개를 추가로 요청. 3열로도 결과는 나옴 |

**`W-` 는 그냥 넘어가도 파일은 나옵니다.** 다만 데이터가 불완전하니 원인을 확인하는 게 좋습니다.

## 실패 코드 — 그 단계가 안 됨

| 코드 | 뜻 | 바로 할 일 |
|---|---|---|
| `E-NORPT` | 폴더에 `.rpt` 가 없음 | `--dir` 경로 확인. 2회차(`fixed_paths.tcl`)를 먼저 |
| `E-RPTMANY` | 폴더에 `.rpt` 가 여러 개 | `--rpt <파일>` 로 지정하거나 코너마다 폴더를 나누기 |
| `E-NOFILE` | 필요한 입력 파일이 없음 | `0_check.py` 로 뭐가 없는지 확인 |
| `E-NOPATH` | 쓸 수 있는 경로가 0개 | `report_timing` 에 `-input_pins` 추가 |
| `E-THTIGHT` | `--slack-max` 가 너무 좁아 0개 | 화면의 '몇 개로 줄일까' 표를 보고 값을 키우기. 리포트 재생성 불필요 |
| `E-ISPARENT` | 코너 폴더가 아니라 상위 폴더를 줌 | 코너 폴더까지 지정, 또는 `4_all_corners.py --root` |
| `E-NONET` | 리포트에 `(net)` 줄이 없음 | `report_timing` 에 `-nets` 추가 |
| `E-NOATTR` | `pin_attr.txt` 에서 속성을 못 읽음 | `report_attribute` 에 `-application` 추가 |
| `E-PINNAME` | 핀 이름이 하나도 안 맞음 | `pin_attr.txt` 를 그 리포트로 다시 만들기 |
| `E-RES0` | Res 를 하나도 못 구함 | SPEF 가 그 코너 것이 맞는지 확인 |
| `E-NOINPUT` | 붙일 값이 없음 (2c) 또는 앞 단계 결과 없음 (5c) | `2a`/`2b` 또는 5a→PT→5b 순서 확인 |
| `E-NOUCTX` | `unique_contexts.tsv` 가 없거나 빔 — 이건 PT 산출물이지 5a 결과가 아님 | 받은 `xtalk/` 가 온전한지 `6_check_xtalk.py` 로 확인 |
| `E-NOTABLE` | 코너 폴더에 `resdist_map.txt` 가 없음 | 코너마다 하나씩 둔다. Res 는 온도마다 다르므로 표도 온도마다 다름 |
| `E-TABLE` | 받은 표를 못 읽음 (`2b_distres_table.py`) | net/res/dist 3열이 맞는지, 헤더 이름·구분자 확인 |
| `E-TABLE0` | 표의 넷 이름이 리포트와 하나도 안 맞음 | 그 디자인의 표가 맞는지, 넷 이름 표기(계층 구분자) 확인 |
| `E-NOROW` | 결과 표에 줄이 0개 | 리포트가 맞는지 확인 |
| `E-PARSE` | PT 출력/리포트 파싱 실패 (5a, 5b) | 앞 단계가 `[ 정상 ]` 으로 끝났는지 확인 |
| `E-BUILD` | 14열 리포트 생성 실패 (5c) | `xtalk/` 안의 tsv 들이 정상인지 |
| `E-NOENGINE` | `_engine/xtalk/` 파서가 없음 | `pt_si_re` 를 통째로 옮기기. `_engine/` 이 빠지면 crosstalk 이 안 됨 |
| `W-NOACTIVE` | 실제로 영향을 준 aggressor 가 0개 (5b) | SI 설정 + coupling SPEF 확인 |
| `E-ISPARENT` | 코너 폴더가 아니라 상위 폴더를 줌 | 코너 폴더까지 지정, 또는 `4_all_corners.py --root` |
| `E-NOANNOT` | 읽을 리포트가 없음 (5a) | 그 폴더에 `.rpt` 나 `*_fixed_annotated.txt` 가 있어야 함 |
| `E-NOCTX` | PT 에 물어볼 넷이 0개 (5a) | 리포트에 `(net)` 줄이 있는지 (`-nets` 누락) |
| `E-NORAW` | PT 출력 없음 (5b) | `pt/xtalk_all.tcl` (hold 면 `xtalk_all_hold.tcl`) 먼저 |
| `E-NOPAIR` | 쌍이 0개 (5b) | SI 설정 + coupling SPEF 확인 |
| `E-NOINPUT` | 앞 단계 결과 없음 (5c) | 5a → `xtalk_all.tcl` → 5b 순서 확인 |

| `W-NODRIVER` | `xtalk_all.tcl` | aggressor 절반 이상이 driver 없음 | 이름 규약 확인 |
| `E-NOFIXEDTCL` | `02_round2*.tcl` | `fixed_paths.tcl` 을 못 찾음 | `1_union.py` 를 먼저. 경로가 다르면 `FIXED` 줄 수정 |
| `E-NOINPUTFILE` | `02_round2.tcl` | db/spef/verilog/sdc 중 없는 파일 | 화면에 찍힌 그 경로를 확인 |
| `E-NOXROOT` | `all_xtalk_one.tcl` | 어느 폴더를 돌지 안 정해짐 | 직접 source 하지 말고 `4_all_corners.py` 가 만든 `run_pt_xtalk.tcl` 을 source |

| `E-NO5A` | `all_xtalk_one.tcl` | 5a 를 돌린 코너가 하나도 없음 | `4_all_corners.py --phase 1` 먼저 |

`fixed_paths.tcl` 은 끝날 때 **요청한 경로 / 측정된 경로** 를 찍습니다.
두 숫자가 같으면 정상입니다. 측정된 쪽이 0 이면 위 `E-NOMEASURED` 입니다.

## 대부분은 이 두 가지입니다

### 리포트 옵션 누락 → `E-NOPATH`, `E-NONET`, `W-DROP`

```tcl
report_timing -delay_type max -path_type full_clock_expanded \
  -nets -input_pins -nosplit -significant_digits 6 \
  -nworst 3 -max_paths 3000 -slack_lesser_than 0.05 > <파일>
```
이 네 개(`-nets -input_pins -nosplit -path_type full_clock_expanded`)가 빠지면 거의 다
여기서 걸립니다.


`dump_attr.tcl` 은 **그 리포트에 나오는 핀·넷만** 뽑습니다. 리포트를 다시 뽑았으면
속성 덤프도 다시 만들어야 합니다.

```tcl
set RPT     "<그 리포트>"
set OUTDIR  "<같은 폴더>"
source dump_attr.tcl
```

## 저에게 전달할 때

이 정도면 충분합니다.

```
2b 에서 E-RES0 떴어
```

숫자를 덧붙이면 더 좋습니다.

```
2b 에서 E-RES0, (net) 105337줄인데 Res 0개
```

`W-` 인 경우는 **비율**이 중요합니다.

```
W-RES, Res 가 34% 비었대
```
