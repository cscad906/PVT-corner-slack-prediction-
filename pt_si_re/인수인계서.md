# 인수인계서 — PVT 코너별 타이밍 데이터 추출

이 문서 하나만 보고 끝까지 가실 수 있게 썼습니다. 표준 PrimeTime 명령과
파이썬 표준 라이브러리만 씁니다. **설치할 것이 없습니다.**

---

## 0. 무엇을 만드는 작업인가

PrimeTime 으로 **여러 코너에서 똑같은 경로 집합을 재측정**하고, 거기에
배선 정보(Dist/Res/Cpin)와 crosstalk 을 붙입니다. 코너마다 파일 2개가
나오면 끝입니다.

```
<코너>_fixed_annotated.txt                     Dist / Res / Cpin 이 붙은 경로
<코너>.path_context_si_compact.by_path.rpt     crosstalk 14열
```

전부 합쳐 **명령 아홉 줄**입니다 — pt_shell 에서 코너마다 네 줄, 셸에서
전체 다섯 줄. 아래는 그 아홉 줄을 언제 어디서 치는지에 대한 설명입니다.

**중요 — 두 갈래는 서로 독립입니다.**

| 갈래 | 만드는 것 | 필요한 것 |
|---|---|---|
| annotation | `_fixed_annotated.txt` | 리포트 + 표 3개 |
| crosstalk | `...by_path.rpt` | 리포트 + PT 의 `xtalk/` |

한쪽이 막혀도 **다른 쪽은 그대로 나옵니다.** 표가 아직 없으면 crosstalk 부터
돌리시면 됩니다.

---

## 1. 받으신 폴더 — 어디에 두고 무엇이 들어 있나

아무 데나 푸시면 됩니다. 폴더 안에서 상대경로로만 움직이므로 **경로를 고칠
것이 없습니다.**

```bash
tar xzf pt_si_re.tar.gz
cd pt_si_re
```

```
pt_si_re/
├─ 0_check.py           환경·입력 점검
├─ 0_trim.py            리포트를 나쁜 것 N개만 남기기 (선택)
├─ 1_union.py           코너 합집합 -> fixed_paths.tcl 을 만든다
├─ 2a_cpin.py           Cpin 붙이기
├─ 2b_distres_table.py  Dist/Res 붙이기 (받은 표를 읽음)
├─ 2c_merge.py          위 둘을 리포트에 합쳐 최종 annotation
├─ run_all.sh           ★ 검사 -> 전부 돌리기 -> 모으기 를 한 줄에
├─ 4_all_corners.py     ★ 위 2a/2b/2c 와 5a/5b/5c 를 코너 전부에 돌리는 배치
├─ 5a_contexts.py       crosstalk - 경로별 victim 넷 뽑기
├─ 5b_pairs.py          crosstalk - victim/aggressor 쌍
├─ 5c_report.py         crosstalk - 14열 리포트
├─ 6_collect.py         ★ 최종 2종만 넘길 형태로 모으기
├─ 7_cut.py             경로 수를 줄이기 (선택)
├─ 8_check_xtalk.py     PT 가 만든 xtalk/ 검사
├─ 9_diagnose.py        N/A 원인 분류
├─ _engine/             ★ 파서 본체. 이게 빠지면 crosstalk 이 안 됩니다
├─ pt/
│  ├─ xtalk_all.tcl        ★ PT 에서 source (setup)
│  └─ xtalk_all_hold.tcl   ★ PT 에서 source (hold)
├─ example/             예시 입력·출력 한 벌
├─ 코드표.md            화면 마지막 코드 -> 조치
└─ README.md            더 자세한 설명
```

`_engine/` 을 빼고 옮기면 crosstalk 단계에서 `E-NOENGINE` 으로 멈춥니다.
**폴더째 옮겨 주십시오.**

`debug/`, `dev/`, `*.pyc` 는 안 쓰셔도 됩니다.

## 2. 환경 확인 — 처음 한 번, 5분

```bash
python3 -V          # 3.6 이상이면 됩니다. 외부 패키지 없음
python3 0_check.py
```

`python3` 이 없거나 2.x 이면 `python3.6`, `/usr/bin/python3` 처럼 실제
이름으로 부르시면 됩니다. **아래 명령의 `python3` 을 그 이름으로 바꿔서
쓰시면 그대로 동작합니다.**

PT 쪽은 라이선스가 **PrimeTime 1석 + PrimeTime-SI 1석**입니다. SI 는
crosstalk 계산에 필요합니다.

## 3. 전체 그림

| | 어디서 | 무엇을 | 코너당 대략 |
|---|---|---|---|
| STEP 1 | PT | 1회차 — 코너마다 위반/위험 경로 뽑기 | 1~3분 |
| STEP 2 | 셸 | 그것을 합쳐 `fixed_paths.tcl` 만들기 | 전체 1회, 수 분 |
| STEP 3 | PT | 2회차 + crosstalk — `source` 두 줄 | 1.5분 |
| STEP 4 | 손 | 받은 표 3개를 코너 폴더에 두기 | — |
| STEP 5 | 셸 | 후처리 — 최종 2종 만들기 | 수 분 |

STEP 2 는 **코너 전부를 모아 한 번만** 합니다. 나머지는 코너마다입니다.

> `fixed_paths.tcl` 을 이미 저희에게서 받으셨다면 **STEP 1 과 2 를 건너뛰고
> STEP 3 부터** 시작하시면 됩니다.

폴더는 이렇게 두시면 편합니다.

```
작업폴더/
├─ round1/corners/          STEP 1 결과가 여기에 쌓입니다
│   └─ (STEP 2 가 여기에 fixed_paths.tcl 을 만듭니다)
└─ round2/
    ├─ tt0p6v25c_Cnom/      코너 하나 = 폴더 하나
    ├─ tt0p65v25c_Cnom/
    └─ ...
```

## STEP 1 — 1회차 리포트 (PT)

코너를 바꿔 로드하실 때마다 아래 한 덩어리를 쳐 주십시오.
`<코너이름>` 만 바꾸시면 됩니다.

```tcl
redirect -file <작업폴더>/round1/corners/<코너이름>.rpt {
  report_timing -delay_type max -path_type full_clock_expanded \
    -nets -input_pins -nosplit -significant_digits 6 \
    -nworst 3 -max_paths 100000 -slack_lesser_than 0.05
}
```

**아래 네 개는 필수입니다. 하나라도 빠지면 뒤 단계가 진행되지 않습니다.**

```
-path_type full_clock_expanded      -nosplit      -input_pins      -nets
```

이미 뽑아 두신 리포트가 있으면 그대로 쓸 수 있습니다. 리포트 맨 위에
`report_timing` 이 자기가 쓴 옵션을 적어 두므로, 거기에 위 네 개가 다
보이면 됩니다.

```
Report : timing
	-path_type full_clock_expanded
	-nosplit
	-input_pins
	-nets
```

## STEP 2 — 측정할 경로 결정 (셸)

코너마다 나쁜 경로가 조금씩 다릅니다. 그걸 **합집합**으로 모아 "이 경로들을
모든 코너에서 똑같이 재라"는 목록을 만듭니다. 코너 간 비교가 되려면 경로
집합이 같아야 하기 때문입니다.

```bash
python3 1_union.py --dir round1/corners --mode setup --max-paths 3000
```

`round1/corners/` 에 세 파일이 생깁니다.

```
fixed_paths.tcl      <- STEP 3 에서 쓰는 경로 목록
union_paths.tsv      경로 표
union_summary.txt    사람이 보기 좋은 요약
```

`--max-paths` 는 **가장 나쁜 slack 부터** 그 개수만 남깁니다. 경로가 많으면
STEP 3 의 PT 시간이 그만큼 늘어나니, 처음에는 300~3000 정도로 잡고 한 코너만
돌려 보신 뒤 늘리시길 권합니다.

`--slack-max -0.1` 처럼 문턱값으로 자르셔도 됩니다. 둘 다 주면 둘 다 걸립니다.

### 전압이 다른 셀(macro 등)이 섞여 있을 때

코너 전압은 스윕되는데 macro 는 고정 레일에 물려 있는 설계라면, 두 전압을
모두 지나는 경로가 생깁니다. 이런 경로는 학습에 쓸 수 없으므로 **세기 전에**
빼야 `--max-paths N` 이 쓸모 있는 N개가 됩니다.

```bash
python3 0_trim.py --dir round1/corners --keep 3000 --voltage auto --out round1/trimmed
python3 1_union.py --dir round1/trimmed --mode setup
```

`--voltage auto` 는 코너 폴더 이름에서 전압을 읽습니다(`tt0p78v25c` -> 0.78).
이름에 그 표기가 없으면 `--voltage 0.78` 처럼 값을 직접 주십시오.

돌리시면 코너마다 이런 줄이 찍힙니다. **이 줄이 보이면 전압 열을 제대로
잡은 것입니다.**

```
  tt0p78v25c_Cnom            0.78        ?        5       1        0        0
      열 'Voltage' 맞음 -> 첫 값 0.78   |  0.137542  0.114834  0.477291 f  0.780000|
```

먼저 `--keep 5` 로 몇 초 만에 확인해 보시는 것을 권합니다. 열을 못 맞추면
그 자리에서 실제 열 이름을 화면에 찍어 줍니다.

## STEP 3 — 2회차 + crosstalk (PT)

여기가 본 측정입니다. **코너를 평소 하시던 대로 로드**하신 다음, **같은
pt_shell 세션에서 이어서** 아래 네 줄만 치시면 됩니다.

### 먼저 세션 설정 두 개

디자인을 로드하실 때 켜 주십시오. **스크립트가 바꾸지 않습니다.**

```tcl
set_app_var si_enable_analysis true                 ;# crosstalk 계산에 필요
set_app_var timing_save_pin_arrival_and_slack true  ;# 핀별 도착시각/slew 조회에 필요
```

`si_enable_analysis` 가 꺼져 있으면 crosstalk 값이 **전부 0** 으로 나옵니다.
스크립트가 시작할 때 확인해 경고를 띄웁니다만 값 자체는 못 살립니다.

SPEF 는 coupling 이 살아 있는 것이어야 합니다
(`read_parasitics -keep_capacitive_coupling`, StarRC `COUPLING_CAP: YES`).

### 그리고 네 줄

```tcl
pt_shell> cd <작업폴더>/round2/<코너이름>
pt_shell> source <pt_si_re경로>/round1/corners/fixed_paths.tcl
pt_shell> set XT_DIR "xtalk"
pt_shell> source <pt_si_re경로>/pt/xtalk_all.tcl
```

`set XT_DIR "xtalk"` 를 써 주십시오. 이것을 안 주시면 결과가
`<코너폴더>/<db이름>/xtalk/` 으로 들어가는데, STEP 5 의 파이썬은
`<코너폴더>/xtalk/` 을 보므로 나중에 옮기셔야 합니다. **코너마다 폴더가
이미 나뉘어 있으니 db 이름으로 한 번 더 나눌 필요가 없습니다.**

한 줄이라 잊기 쉬우시면 그냥 안 주셔도 됩니다. 그 경우 STEP 5 전에
한 줄만 치시면 됩니다.

```bash
# db 이름 폴더 안에 있는 xtalk/ 를 코너 폴더 바로 아래로 올린다
for d in round2/*/*/xtalk ; do mv "$d" "$(dirname $(dirname $d))/xtalk" ; done
```

(bash 문법입니다. csh/tcsh 를 쓰시면 `bash` 를 한 번 치고 돌리시면 됩니다.
빈 db 이름 폴더가 남는데 그냥 두셔도 무방합니다.)

`XT_DIR` 은 **한 번 쓰고 지워집니다.** 코너마다 다시 주셔야 합니다.
setup 과 hold 를 같은 폴더에서 돌리시면 서로 덮어쓰므로, 작업 폴더를
따로 두셔야 합니다(7장).

- **코너 폴더에서 돌려 주십시오.** `fixed_paths.tcl` 은 **지금 있는 폴더
  이름**을 리포트 이름으로 씁니다. `round2/tt0p6v25c_Cnom` 에서 돌리면
  `tt0p6v25c_Cnom.rpt` 가 됩니다.
- 뒤 파일이 앞 파일이 방금 만든 리포트를 알아서 찾습니다. 경로를 적어
  주실 필요가 없습니다.
- 화면 마지막에 `[ OK-XTALK ]` 이 보이면 정상입니다.

폴더 이름과 상관없이 이름을 정하고 싶으시면 `fixed_paths.tcl` 맨 위
`set CORNER` 한 줄을 고치시면 됩니다.

### 나오는 것

```
round2/<코너>/<코너>.rpt              <- fixed_paths.tcl
round2/<코너>/xtalk/                  <- xtalk_all.tcl (XT_DIR 을 준 경우)
   unique_contexts.tsv       물어본 넷 목록
   context_raw.rpt           report_delay_calculation 원문
   victim_windows.tsv        victim 핀 도착시각/slew
   aggressor_windows.tsv     aggressor 드라이버 도착시각/slew
   run_info.txt              이번 실행이 무엇을 읽고 무엇을 썼는지
round2/<코너>/xtalk_all_run.log       화면에 찍힌 것 전부 (자동)
```

`xtalk_all_run.log` 와 `run_info.txt` 는 **스크립트가 알아서 남깁니다.**
따로 `tee` 를 거시거나 화면을 복사하실 필요가 없습니다. 문제가 생기면
이 두 파일만 보내 주시면 됩니다.

### 세션에 미치는 영향은 없습니다

드리는 tcl 은 **읽기만 합니다.** 아래를 하나도 하지 않습니다.

```
remove_design   read_verilog / link_design / read_sdc / read_parasitics
set_app_var     update_timing     write_* 계열     save_session
```

이미 올려 두신 디자인을 그대로 두고 리포트만 뽑습니다. 돌리신 뒤에도 세션
상태가 그대로이므로 이어서 다른 작업을 하셔도 됩니다.

### 쓰는 명령 전부

커스텀 명령이나 외부 도구는 없습니다.

```
report_timing       report_delay_calculation
get_pins   get_nets   get_attribute   get_app_var   get_designs
get_object_name   sizeof_collection   index_collection
redirect   source   file / open / gets / puts   (Tcl 기본)
```

### `XT_DIR` 을 안 주시면 db 이름으로 갈립니다

`XT_DIR` 이 없으면 `link_path` 에서 db 이름을 읽어 그 이름으로 폴더를
만듭니다. 코너를 한 자리에서 여러 개 돌리셔도 서로 안 덮어쓰게 하려는
장치입니다.

```
<db이름>/xtalk/          setup
<db이름>_hold/xtalk/     hold
```

코너마다 폴더를 나누신다면 이 장치가 필요 없으므로, 위처럼
`set XT_DIR "xtalk"` 를 주시는 편이 뒤가 간단합니다.

## STEP 4 — 표 3개를 코너 폴더에 두기 (손)

annotation 갈래에만 필요합니다. crosstalk 은 이 표가 없어도 됩니다.

**코너 폴더마다** 아래 세 파일을 이 이름 그대로 두시면 배치가 알아서
집습니다. 이 이름은 저희 쪽 규약이고, 만들어 주는 코드는 없습니다.

```
round2/<코너>/cpin_map.txt     2열 이상:  핀이름 <TAB> pin_cap
round2/<코너>/res_map.txt      2열:       넷이름 <TAB> res
round2/<코너>/dist_map.txt     2열:       넷이름 <TAB> dist
```

헤더는 있어도 없어도 되고, 구분자는 탭·쉼표·띄어쓰기 아무거나 됩니다.

### 왜 코너마다 따로 필요한가

실측(BoomCoreV3, 82,472줄) 결과입니다.

| | 전압에 따라 | 온도에 따라 |
|---|---|---|
| Dist | 안 변함 | 안 변함 (배치 좌표라서) |
| Res | 안 변함 | **크게 변함** (25C->125C 전 넷 +39%) |
| Cpin | **변함** | **변함** (Liberty 에서 오므로) |

- `cpin_map.txt` 는 **코너마다** 새로 필요합니다. 0.6V 와 0.8V 를 재 보니
  값이 중앙값 5.95%, 최대 8.27% 달랐습니다.
- `res_map.txt` 는 **온도마다** 다르면 됩니다. 같은 온도의 여러 전압
  코너에는 같은 표를 복사해 두셔도 됩니다.
- `dist_map.txt` 는 전 코너 공통이어도 됩니다.

### Cpin 표를 PT 에서 뽑는 법

둘 중 **편하신 쪽 하나**면 됩니다. 값은 같습니다.

```tcl
# (가) 설계 핀 -- 제일 정확합니다. 핀 수만큼 나옵니다
foreach_in_collection p [get_pins -hierarchical *] {
    puts "[get_object_name $p]\t[get_attribute -quiet $p pin_capacitance_max]"
}

# (나) 라이브러리 핀 -- 훨씬 짧습니다(셀 종류 수만큼)
foreach_in_collection p [get_lib_pins *] {
    puts "[get_object_name $p]\t[get_attribute -quiet $p pin_capacitance]"
}
```

(나)에서는 attribute 이름이 `pin_capacitance` 입니다. `capacitance` 나
`pin_capacitance_max` 를 쓰면 빈 값이 나옵니다.

열이 더 있어도 됩니다 — 어느 열이 Cpin 인지 저희 쪽에서 골라냅니다. 다만
**셀 이름만** 있거나 **넷 이름만** 있는 표는 못 씁니다. Cpin 은 핀마다 다른
값이라 핀 구분이 있어야 합니다.

### Res / Dist 표 대신 SPEF 를 바로 읽어도 됩니다

`res_map.txt` / `dist_map.txt` 를 따로 만드시는 것보다, **가지고 계신 SPEF 를
그대로 읽히는 편이 간단**할 수 있습니다. 결과는 같은 `distres.tsv` 입니다.

```bash
# 코너마다 한 번
python3 2b_distres.py --dir round2/<코너> --spef <그 코너의 .spef>

# SPEF 가 여러 개면 폴더를 주십시오. 코너 이름의 온도와 RC 코너로 골라 줍니다
python3 2b_distres.py --dir round2/<코너> --spef-dir <SPEF폴더>
```

코너 폴더에 `design.spef` 라는 이름으로 두셔도 자동으로 집습니다.

이 길로 가시면 STEP 5 의 (2)번을 이렇게 바꾸십시오. 2b 를 위처럼 이미
돌리셨으므로 배치에서는 빼는 것입니다.

```bash
python3 4_all_corners.py --root round2 --phase 1 --only 2a,2c
```

`4_all_corners.py --phase 1` 을 그냥 돌리면 **표 방식(`2b_distres_table.py`)**
으로 갑니다. 표가 없으면 `E-NOTABLE` 로 멈춥니다 — 그때 위 두 길 중 하나를
고르시면 됩니다.

SPEF 는 coupling 이 없어도 됩니다. Dist/Res 만 읽기 때문입니다
(coupling 이 필요한 것은 STEP 3 의 crosstalk 쪽입니다).

## STEP 5 — 후처리 (셸)

`pt_si_re` 폴더에서 아래를 순서대로 치시면 됩니다. `--root` 에는 **코너
폴더들이 들어 있는 상위 폴더**를 줍니다 (코너 폴더 하나가 아닙니다).

### 한 줄로 끝내기 (권장)

```bash
sh run_all.sh round2 deliver setup
```

아래 (1)~(4)를 순서대로 다 합니다. 코너를 나눠 돌리시려면 앞에
`JOBS=4` 를 붙이십시오.

```bash
JOBS=4 sh run_all.sh round2 deliver setup
PY=/usr/synopsys/pt/.../python3 sh run_all.sh round2 deliver setup   # 파이썬 지정
EXTRA=--skip-done sh run_all.sh round2 deliver setup                 # 이어서
```

hold 는 **작업 폴더를 따로 두고** 마지막 인자만 바꾸십시오.

```bash
sh run_all.sh round2_hold deliver hold
```

### 한 단계씩 치실 때

```bash
# (1) PT 가 만든 xtalk/ 가 온전한지 먼저 검사
python3 8_check_xtalk.py --root round2

# (2) annotation + crosstalk 을 한 번에  (2a 2b 2c 5a 5b 5c)
python3 4_all_corners.py --root round2 --phase 3

# (3) 최종 2종만 모으기
python3 6_collect.py --root round2 --out deliver --mode setup
```

`--phase 3` 은 묶음 1(annotation)과 묶음 2(crosstalk)를 한 번에 돕니다.
**둘은 서로 독립이라, 표가 없어 annotation 이 막힌 코너에서도 crosstalk 은
그대로 나옵니다.**

나눠서 도시려면 예전처럼 두 번 치셔도 됩니다. 결과는 같습니다.

```bash
python3 4_all_corners.py --root round2 --phase 1      # annotation 만
python3 4_all_corners.py --root round2 --phase 2      # crosstalk 만
```

각 단계는 화면 마지막에 `[ OK-... ]` / `[ W-... ]` / `[ E-... ]` 코드를
찍습니다. `W-` 는 경고(계속 진행), `E-` 는 정지입니다.

### 자주 쓰는 옵션

```bash
--skip-done       이미 결과가 있는 단계는 건너뛴다. 중간에 끊겼을 때 안전
-j 4              코너 4개를 동시에. 결과는 완전히 같다
--only 2b         그 묶음 안에서 한 단계만
--quiet           단계별 출력을 숨기고 결과 표만
```

### 경로 수를 줄여야 하면 (선택)

`1_union.py --max-paths` 는 PT **전에**만 쓸 수 있습니다. 이미 다 돌리신
뒤에 줄이려면 `6_collect.py` **앞에** 한 줄을 끼웁니다.

```bash
python3 7_cut.py     --root round2 --keep 300
python3 6_collect.py --root round2_top300 --out deliver --mode setup
```

`round2_top300/` 에 **사본**을 만듭니다. **원본은 건드리지 않습니다.**

`### FIXED_PATH` 블록을 **파일 순서대로 앞에서 N개** 남깁니다. idx 번호로
자르지 않습니다 — PT 가 못 잡은 경로는 그 idx 가 빠지므로 번호로 걸면 N개보다
적게 남기 때문입니다.

## 6. 최종 산출물 — 저희에게 넘겨 주실 것

```
deliver/setup/
├─ report.<코너>_fixed_annotated.rpt                       annotation
└─ xtalk/
   └─ xt.<코너>.path_context_si_compact.by_path.rpt        crosstalk
```

코너마다 이 2개, 그게 전부입니다. `6_collect.py` 가 이 모양으로 모아 주고
이름 앞에 `report.` / `xt.` 를 붙입니다(복사이므로 원본은 그대로 남습니다).

코너 하나가 두 파일 중 하나만 있으면 그 코너는 화면에 `annotation 없음`
으로 찍히고 있는 것만 모입니다. 넘기시기 전에 그 목록이 비어 있는지 봐
주십시오.

중간 파일(`cpin.tsv`, `distres.tsv`, `xtalk/` 안의 것들)은 넘기실 필요
없습니다. 다만 **문제가 있었던 코너만은** `xtalk/run_info.txt` 와
`xtalk_all_run.log` 를 같이 주시면 원인을 바로 알 수 있습니다.

## 7. hold 는 완전히 별개 세트입니다

setup 과 hold 는 섞이면 안 됩니다. **작업 폴더를 따로 두고** 처음부터 끝까지
따로 도십시오.

| | setup | hold |
|---|---|---|
| STEP 1 | `-delay_type max` | `-delay_type min` |
| STEP 2 | `--mode setup` | `--mode hold` |
| STEP 3 | `pt/xtalk_all.tcl` | `pt/xtalk_all_hold.tcl` |
| STEP 5 | `--mode setup` | `--mode hold` |

`xtalk_all.tcl` 과 `xtalk_all_hold.tcl` 은 **두 줄만 다릅니다**
(`DELAY_TYPE`, 읽는 리포트 이름).

`8_check_xtalk.py` 는 setup/hold 를 PT 원문에서 자동 판별하므로 `--mode` 를
붙이실 필요가 없습니다.

## 8. 막혔을 때

화면 마지막 **코드 하나**만 알려 주시면 어디가 막혔는지 바로 알 수 있습니다.
전체 목록과 조치는 `코드표.md` 에 있습니다. 자주 나오는 것만 추리면:

| 코드 | 뜻 | 하실 것 |
|---|---|---|
| `E-NODESIGN` | PT 에 디자인이 안 올라와 있음 | `read_verilog` -> `link_design` -> `read_sdc` -> `read_parasitics` 를 먼저 |
| `E-NORPTFILE` | 읽을 `.rpt` 를 못 찾음 | 그 폴더에서 `fixed_paths.tcl` 을 먼저 돌리셨는지 |
| `E-NOAGGR` | aggressor 를 하나도 못 찾음 | `printvar si_enable_analysis`, coupling SPEF 확인 |
| `E-XCALC0` | 넷을 하나도 계산 못 함 | `xtalk/context_raw.rpt` 의 `message=` 줄 |
| `W-RPTCUT` | 읽은 리포트가 도중에 잘림 | `fixed_paths.tcl` 을 끝까지 다시 |
| `E-NONET` | 리포트에 `(net)` 줄이 없음 | `report_timing` 에 `-nets` 추가 |
| `E-NOPATH` | 쓸 수 있는 경로가 0개 | `report_timing` 에 `-input_pins` 추가 |
| `E-NOTABLE` | 코너 폴더에 `res_map.txt` / `dist_map.txt` 가 없음 | STEP 4 참조. 코너마다 두 개 |
| `E-TABLE0` | 표의 넷 이름이 리포트와 하나도 안 맞음 | 그 디자인의 표가 맞는지, 계층 구분자 표기 확인 |
| `E-NOENGINE` | `_engine/` 이 없음 | 폴더째 다시 옮기기 |
| `E-VNAME` | 코너 이름에서 전압을 못 읽음 | `--voltage 0.78` 처럼 값을 직접 주기 |
| `W-NETKEY` | 표가 넷 이름 기준이라 리시버가 여럿인 넷은 같은 값을 받음 | 실패가 아닙니다. 그대로 진행됩니다 |

N/A 가 남았을 때는 원인을 갈라 줍니다.

```bash
python3 9_diagnose.py --dir round2/<코너>
```

## 9. 주의 — 세 가지만

1. **`_engine/` 을 빼고 옮기지 마십시오.** crosstalk 파서 본체입니다.
2. **setup 과 hold 를 한 폴더에서 돌리지 마십시오.** 리포트 이름이 같아
   덮어씁니다.
3. **`unique_contexts.tsv` 는 PT 산출물입니다.** 파이썬이 만들지도 덮지도
   않습니다. PT 가 실제로 무엇을 물어봤는지 담은 유일한 기록이라 그렇습니다.
   지우지 말아 주십시오.

`xtalk/` 안의 파일은 다시 돌리시면 **덮어씁니다.** 지우고 다시 돌리실 필요는
없습니다.

## 11. 한 코너만 먼저 돌려 보시려면

전체를 걸기 전에 코너 하나로 끝까지 가 보시는 것을 권합니다.

```bash
# STEP 2 를 5개만 (몇 초). 전압 열을 맞췄는지 여기서 확인됩니다
python3 0_trim.py --dir round1/corners --keep 5 --voltage auto --out /tmp/vtest

# STEP 5 를 코너 하나만. --dir 에는 코너 폴더를 바로 줍니다
python3 8_check_xtalk.py    --root round2
python3 2a_cpin.py          --dir round2/<코너>
python3 2b_distres_table.py --dir round2/<코너>
python3 2c_merge.py         --dir round2/<코너>
python3 5a_contexts.py      --dir round2/<코너>
python3 5b_pairs.py         --dir round2/<코너>
python3 5c_report.py        --dir round2/<코너>
```

`4_all_corners.py` 는 위 여섯 개를 코너 전부에 돌려 주는 배치일 뿐입니다.
`--root` 에는 **코너들이 든 상위 폴더**를, 낱개 스크립트의 `--dir` 에는
**코너 폴더 자체**를 줍니다. 이 둘을 바꿔 주시면 `E-ISPARENT` 로 멈춥니다.

`example/` 에 입력부터 최종 산출물까지 한 벌이 들어 있습니다. 결과가 어떤
모양이어야 하는지 비교해 보실 수 있습니다.
