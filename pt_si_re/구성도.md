# 전체 구성

## 폴더 모양

```
setup/                                      <- --root 는 여기
│                                              (SPEF 는 이제 안 씀)
└─ tt0p6v25c_Cnom/                          <- 코너 하나 = 폴더 하나
   │
   │  [입력] 담당자분께 받는 것
   ├─ tt0p6v25c_Cnom.rpt        fixed_paths.tcl 결과. 폴더당 하나만
   ├─ cpin_map.txt              받은 Cpin 표 (또는 pin_attr.txt)
   ├─ res_map.txt               받은 Res 표   2열: 넷 / res    <- 코너마다
   ├─ dist_map.txt              받은 Dist 표  2열: 넷 / dist   <- 코너마다
   │
   │  [묶음 1 = annotation]
   ├─ cpin.tsv                                      <- 2a
   ├─ distres.tsv                                   <- 2b   (표를 읽는다. SPEF 안 씀)
   ├─ tt0p6v25c_Cnom_fixed_annotated.txt            <- 2c   ★ 산출물 1
   │
   │  [묶음 2 = crosstalk]
   ├─ tt0p6v25c_Cnom.path_context_si_compact.by_path.rpt   <- 5c  ★ 산출물 2
   │
   └─ xtalk/
      ├─ unique_contexts.tsv    <- PT (xtalk_all.tcl)    5a 는 안 건드린다
      ├─ context_raw.rpt        <- PT
      ├─ victim_windows.tsv     <- PT
      ├─ aggressor_windows.tsv  <- PT
      ├─ path_summary.tsv       <- 5a
      ├─ path_victim_nets.tsv   <- 5a    5a 를 도는 유일한 이유
      ├─ context_summary.tsv    <- 5b
      ├─ active_features.tsv    <- 5b
      └─ compact_flat.tsv       <- 5c

hold/                                       <- 별도 트리. 섞으면 안 됨
└─ (같은 모양)
```

## 흐름

```
[PT]  담당자분. 우리는 PT 를 못 돌린다. 드리는 것은 tcl 두 개뿐이다.
        cd setup/<코너>
        source fixed_paths.tcl          -> <코너>.rpt
        source pt/xtalk_all.tcl         -> xtalk/ 4개  (hold 는 xtalk_all_hold.tcl)
        source dev/dump_attr.tcl        -> pin_attr.txt  (cpin_map.txt 받았으면 생략)

  ↓ 받은 것을 코너 폴더에 두고, res_map.txt / dist_map.txt 도 코너마다 넣는다

[셸]  4_all_corners.py --root setup                 묶음 1  코너마다 2a -> 2b -> 2c
[셸]  4_all_corners.py --root setup --phase 2       묶음 2  코너마다 5a -> 5b -> 5c
[셸]  6_collect.py --root setup --out deliver --mode setup
```

두 묶음은 서로 독립이라 순서를 바꿔도 되고, 한쪽이 막혀도 다른 쪽은 나온다.

## 이번에 바뀐 것

| | 전 | 후 |
|---|---|---|
| Dist/Res | `2b_distres.py` 가 SPEF 를 읽음 | `2b_distres_table.py` 가 **받은 표**(`res_map.txt` + `dist_map.txt`)를 읽음 |
| SPEF | `--spef-root` 필수. 못 고르면 `E-SPEFPICK` 으로 정지 | **안 씀.** 묶음 1 에서 SPEF 검사 자체가 없음 |
| 묶음 1 | 2a 2b 2c **5a** | 2a 2b 2c — annotation 만 |
| 묶음 2 | 5b 5c | **5a** 5b 5c — crosstalk 만 |
| PT 자리 | 두 묶음 **사이** | 두 묶음보다 **앞** (담당자분이 먼저 다 돌려 주심) |
| `unique_contexts.tsv` | 5a 가 만들어 PT 것을 덮어씀 | **PT 것만 남는다.** 5a 는 안 건드림 |
| phase 1 뒤 안내 | `run_pt_xtalk.tcl` 을 만들어 "pt_shell 에서 source" | 없앰. 우리가 못 하는 일이었음 |

`W-NETKEY` 는 표가 3열(넷 이름 키)이라 매번 뜬다. 실패가 아니고 문제로도 안 센다.
표에 driver/receiver 핀 열 2개가 있으면 `OK-DISTRES` 로 바뀐다.
